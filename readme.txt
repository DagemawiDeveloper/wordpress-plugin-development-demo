A production-style reference plugin for signed webhooks, REST endpoints, AJAX actions, logging and retryable WordPress integrations.

== Description ==

WP Integration Toolkit demonstrates maintainable WordPress integration patterns including:

* Signed outbound webhooks
* Authenticated inbound REST webhooks
* Encrypted secret storage
* Custom database logging
* AJAX test and retry actions
* Capability and nonce checks
* Hooks for plugin/theme extensibility
* Responsive admin interface

This repository is intended as an engineering showcase and reference implementation.
